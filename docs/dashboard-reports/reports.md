# Monthly reports

**Who:** Engineers & Admins

Use this to generate or download a PDF summary of a given month's metrics, rather than reconstructing them from the dashboard by hand.

1. Open **Monthly reports**.
2. Pick a month and click **Generate now**.
3. Generation runs in the background, so the page confirms with "Report for YYYY-MM queued — refresh in a minute." rather than generating the PDF immediately.
4. Refresh the page after a minute to see the updated status.

## Statuses

Each report moves through:

- **Pending** — queued, not yet started.
- **Generating** — in progress.
- **Ready** — done; a **Download PDF** link appears, giving you a file named `monthly-YYYY-MM.pdf`.
- **Failed** — generation didn't complete; generate it again.

## What happens next

Last month's report also generates automatically on the 1st of each month, so you don't need to remember to request it yourself — you'll usually just be downloading it.
