# Register equipment

**Who:** Engineers & Admins

Do this when a new device arrives at the hospital and needs to be added to the registry.

1. From the **Equipment Registry**, click **+ Add Equipment**.
2. Fill in the form:
      - **Name**
      - **Manufacturer**
      - **Vendor**
      - **Model number**
      - **Serial number** — must be unique across the registry.
      - **Department** — select from the list.
      - **Is critical asset** — tick for devices like MRI or CT machines. Downtime is tracked only for critical assets.
      - **Purchase date**
      - **Installation date**
3. Save the form.

**What happens next:** The device appears in the registry with status **Working**.
